# e-plantShopping

## Project Overview

e-plantShopping is a React-based online plant shopping application that allows users to browse a variety of plants, add items to a shopping cart, and manage their purchases through an interactive and user-friendly interface.

### Features

- Browse different categories of plants
- View plant details and pricing
- Add plants to a shopping cart
- Update cart quantities
- Remove items from the cart
- Responsive and modern user interface

### Technologies Used

- React
- JavaScript
- Vite
- CSS

### Purpose

This project was created as part of the Paradise Nursery Shopping Application final project to demonstrate front-end development skills using React and state management concepts.
